# سناریوی ویدیوها

یک فایل برای هر ویدیو، با همان slug آموزش. هر سناریو دو ستون دارد:

- **کار روی صفحه** — برای رضا عبدالهی، که با OBS ضبط می‌کند: دقیقاً کجا کلیک کند.
- **گفتار** — برای یگانه جعفری، که صدا را ضبط می‌کند.

## روال ضبط

1. **اول صدا.** خانم جعفری گفتار هر صحنه را جدا ضبط می‌کند (`01.wav`، `02.wav`، …).
   مکث‌های بین جمله‌ها بعداً بریده می‌شوند؛ عجله لازم نیست.
2. **بعد تصویر.** رضا صدای هر صحنه را پخش می‌کند و هم‌زمان کار روی صفحه را
   ضبط می‌کند. بریدن ویدیو برای جا شدن روی صدا آسان است؛ برعکسش نه.
3. **ادیت** در DaVinci Resolve (رایگان) یا CapCut.
4. **زیرنویس:** متن ستون گفتار، بعد از ادیت با زمان‌بندی نهایی، می‌شود فایل SRT.

## تنظیمات ضبط

- OBS: ۱۹۲۰×۱۰۸۰، ۳۰ فریم
- زوم مرورگر حدود ۱۲۵٪ تا متن روی گوشی خوانا باشد
- پروفایل مرورگر تمیز: بدون بوکمارک، بدون افزونه، اعلان‌های سیستم خاموش
- تم روشن، و **همان workspace دمو** که اسکرین‌شات‌ها از آن‌اند
  («موبایل‌کده نگین»؛ `docs/academy/` در ریپوی اپ)
- نشانگر ماوس آرام؛ قبل از هر کلیک یک لحظه روی دکمه بماند

## قالب ثابت هر ویدیو

- **۰ تا ۵ ثانیه:** قلاب — مسئله‌ای که ویدیو حل می‌کند، نه «سلام، در این ویدیو…»
- **آخر:** قاب ثابت ۵ ثانیه‌ای: «شروع ۳۰ روز رایگان — app.dofixo.ir»
- **طول:** حدود دو دقیقه؛ اگر بیشتر شد، یعنی دو ویدیوست
- **عنوان در آپارات و یوتیوب:** همان عنوان آموزش؛ توضیح: لینک آموزش نوشتاری
  و لینک ثبت‌نام
