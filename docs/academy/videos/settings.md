# ویدیو: تنظیمات دوفیکسو

- **آموزش نوشتاری:** `/academy/tutorials/settings/`
- **طول هدف:** حدود ۲:۰۰
- **عنوان آپارات/یوتیوب:** تنظیمات دوفیکسو؛ اطلاعات تعمیرگاه، لوگو و فاکتور
- **آماده‌سازی:** وارد workspace دمو با حساب سوپر ادمین، روی «تنظیمات». یک فاکتور
  تعمیر باز برای قدم آخر.
  ⚠️ «ذخیره تنظیمات» را نزنید و تصویر تازه‌ای بارگذاری نکنید؛ بارگذاری همان لحظه
  ذخیره می‌شود. فقط ماوس را روی فیلدها ببرید.
