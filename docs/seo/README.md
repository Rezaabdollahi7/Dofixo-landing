# مستندات SEO و فنی دوفیکسو — نقطهٔ مرجع

این پوشه خروجی یک سری بررسی چندمرحله‌ای (Search Console، ادیت کد ریپو،
تأیید میدانی Production، و طرح راه‌ترازی فرم تماس) است و قرار است **تنها
منبع حقیقت** برای کارهای بعدی SEO/فنی سایت دوفیکسو باشد — به‌جای
پراکندگی یافته‌ها در گفتگوها یا داک‌های جداگانه.

## رابطه با مستندات موجود

این پوشه **جایگزین** `docs/academy/*` نمی‌شود — آن‌ها منبع حقیقت محتوای
مرکز آموزش (`keyword-map.md`، `product-facts.md`، `writing-guide.md`،
`authors.md`) باقی می‌مانند و این اسناد به آن‌ها ارجاع می‌دهند، نه
تکرارشان می‌کنند. `CLAUDE.md` / `AGENTS.md` ریشهٔ ریپو هم بدون تغییر
باقی مانده‌اند؛ این پوشه مکمل آن‌هاست، نه جایگزین.

## منبع یافته‌ها

یافته‌های این اسناد از چهار بررسی مجزا می‌آیند که در جلسات قبلی (خارج از
این ریپو، در Composio/Google Search Console و از طریق درخواست‌های HTTP
واقعی به production) انجام شده‌اند:

1. تحلیل Google Search Console (`sc-domain:dofixo.ir`، ۲۰۲۶-۰۷-۳۰ تا ۲۰۲۶-۱۱-۱۰).
2. ادیت فنی SEO کد ریپو (کامیت `0e9db69`).
3. تأیید میدانی Production با درخواست‌های HTTP واقعی (بدون POST به فرم‌ها).
4. بررسی معماری فرم تماس و زیرساخت موجود.

هیچ‌کدام از این بررسی‌ها تغییری در کد یا رفتار سایت ایجاد نکرده‌اند؛ این
پوشه اولین تغییر واقعی (فقط مستندسازی) است.
